# Mehdi Aminazadeh — Academic portfolio

The published academic portfolio at https://mehdi-amina.github.io/.

GitHub Pages serves the compiled React application directly from `main` at the repository root. `.nojekyll` keeps the prebuilt files unchanged. Navigation uses URL fragments, so project links work with static hosting.

This deployment includes the separate Fraunhofer IOSB and IESE entries, project summaries, source-grounded result figures, and the detailed Isfahan traffic analysis. Figure source notes and supporting data are in `results/`.

The theme is adapted from AcademicPages; its MIT license is included in `ACADEMICPAGES-LICENSE.txt`.
